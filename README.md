# AI-Virtual-Mouse
AI Virtual Mouse 🖱️🤖

AI Virtual Mouse is a computer vision-based project that allows users to control their mouse pointer and perform basic actions using hand gestures, without any physical mouse. This project uses AI and real-time hand tracking to make human-computer interaction more intuitive and touchless.

Features
Move the mouse pointer with hand gestures.
Left-click and right-click using simple gestures.
Scroll and drag functionalities.
Works in real-time using webcam input.
Lightweight and easy to set up.
Technologies Used
Python
OpenCV – for real-time video capture and image processing
MediaPipe – for hand tracking and gesture recognition
PyAutoGUI – to control mouse actions programmatically
Installation
Install dependencies:
pip install -r requirements.txt
Run the application:
python virtual_mouse.py
Usage
Place your hand in front of the webcam.
Follow the gestures shown in the demo to move the pointer, click, or scroll.
Adjust the sensitivity or settings in the config file if needed.
